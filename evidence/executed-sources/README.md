# Exact historical execution source

`freeze_gauge_recipe.py` is retained byte for byte to resolve the generator SHA256 in the gauge-recipe manifests. Its original execution path is preserved for provenance; use the portable entry points under `tools` for new builds. The reviewed v2 search is the selected GPU implementation; `experiments/gauge/gauge_search_v1.py` preserves the earlier pilot implementation and its stated limitations.
