# Draft: source-reproducible FeMoCo chemistry compiler and local verification

I am sharing QVC Chemistry Compiler: https://github.com/Agnuxo1/qvc-chemistry-compiler

The repository contains a frozen chemistry recipe, the attributed source compiler, exact output hashes, full local verifier receipts, reproducibility instructions and scientific figures. The selected chemistry uses 14,848 Toffolis and 427 qubits, giving a local reference/cost ratio of 11.232890314 with the archived reference. It has not been submitted as a project result on Kaggle.

The project builds on marculera's public pipeline and the other authors credited in the repository. Original contributions are offered under MIT OR Apache-2.0; Apache-derived material preserves its upstream terms and notices.

The optimized public invsqrt/DQI files have passed local circuit checks, but their exact generating sources remain an open recovery item. The source-complete three-task control uses the organizer reference circuits for those tasks. The repository makes that distinction explicit.
