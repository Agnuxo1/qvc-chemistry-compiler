# Competition and publication record

Competition: [Google Quantum AI — Verifiable Quantum Circuit Compilation](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation).

Rules were retrieved again on 2026-11-10 using the authenticated read-only Kaggle API. The [official rules](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation/rules) do not require a private repository. They allow public code sharing made available to all participants on the competition forum, prohibit private sharing outside a team, and require Apache-2.0 for a winning submission and its generating source. The user explicitly authorized public publication while the contest is open.

The [host clarification](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation/discussion/752010) requires an exact circuit generator for all benchmarks and all prizes. A [follow-up question](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation/discussion/755488) asking whether a pinned compiled input plus transforms qualifies had no reply at this retrieval. We therefore do not assume it qualifies.

The public sharing announcement is prepared in FORUM_DRAFT.md. No final Kaggle submission, leaderboard acceptance or prize eligibility is claimed. The release record distinguishes GitHub publication from competition submission.
