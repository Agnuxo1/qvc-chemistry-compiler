# Exact-source recovery: I01

Acceptance: a real source algorithm must generate the selected optimized invsqrt and DQI outputs, with exact SHA256 matches, followed by full native verification. A downloader, circuit copier or encoded KMB replay does not meet this project's source gate. The gate remains open until demonstrated.

| Target | Required SHA256 | Current evidence |
|---|---|---|
| invsqrt | 26ebf39df3b13e5fd2d923d1b9988043b107b64f6e21efc5cc9bc76f5d56adec | Public gengsr file; 46-CSWAP shifter on maoxin123's 62-qubit circuit; full native PASS |
| DQI | e9f54be304cbdcda7306729c335b1a2314a45d0ca818e05cf60e45ddee969bc4 | Public Atakan terminal-readout circuit selected by gengsr; two full native checks |

The latest fetched gengsr and Syed notebooks copy compiled files with hash checks. Atakan's notebook authenticates a compiled validation payload; it does not include the decoder generator. The maoxin notebook reference could not be pulled during this recovery; no explanation of its availability is inferred.

The complete public mrmeows dataset was inventoried (2,704 files), including a source-backed invsqrt ancestor reported at 20.0565x. Dmitrii Gluzdov's public factorization dataset was inventoried (833 files), including 117 Python source modules and a source-backed round12 DQI ancestor. These are useful algorithm sources; neither has been demonstrated to generate the two target hashes. The earlier James Day source archive and SomeJoint's 25 partial sources are also recorded in the private research inventory. No ancestor's PASS is transferred to a different circuit.

The PC's QVC project and repository source scan is saved with its scope. A separate server inventory covered 179 QVC-related locations, including identified job workspaces: 122 source files were inspected for target-family markers. Its three matches were organizer-reference generators. The local QVC scan had nine source matches, including reference generators and audit/fetch tools. Neither scan established an exact optimized generator. A broader D-drive content scan exceeded its 120-second bound; it is not represented as exhaustive. See [recovery evidence](../evidence/source-recovery.json).

Compare the local and server workspaces and original job inputs against those recovered source trees. Trace each dependency and source transformation. If the exact performance algorithms cannot be recovered, develop and independently verify a new source-generated portfolio before promoting it; version and measure any performance change explicitly. The source-complete organizer-reference portfolio remains an independently usable control, not evidence that optimized I01 is closed.
